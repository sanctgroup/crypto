SANCT CRYPTO 0.3.0: RELEASE SECURITY GATE FIX
1 November 2026

Outcome
The two dependency advisories blocking publication are removed from the resolved build. cargo audit reports zero known vulnerabilities and no informational warnings; cargo deny passes advisories, bans, licenses and sources. There are no advisory ignores. This is not a formal security audit or a guarantee that no unknown vulnerabilities remain.

Implementation
The workspace uses a restricted vendored copy of rPGP 0.21.0. RSA, ECDSA, NIST ECDH, Ed448, X448 and optional OpenPGP PQC providers and their dependencies are removed. rsa, crypto-bigint, elliptic-curve and cx448 are absent from Cargo.lock. No replacement cryptographic primitive was invented. The retained Ed25519/X25519 implementations and legacy Curve25519 formats come from upstream rPGP. Standalone Sanct hybrid ML-KEM support is unchanged.
The vendored crate retains the upstream pgp package name and version for advisory identification. Its README records the source revision, crate checksum, modifications and maintenance requirements. Rust registry publication is disabled for the vendored crate and its consumers, preventing Cargo publication from replacing the restricted path dependency with the unrestricted registry package. Git consumers and the WASM distribution continue to work. Original licenses and a modification notice are included with the WASM package.
Removed-provider key packets return a dedicated fatal error so imported bundles cannot silently discard those subkeys. Public and secret key bundles containing a removed provider are rejected. DSA/ElGamal parsing and public verification code remains, while Sanct's existing private-key policy still permits only Ed25519/X25519 and their legacy forms. cargo-deny additionally bans RSA and crypto-bigint versions before 0.7.6 to prevent reintroduction.
Regression testing exposed a v6 metadata-selection bug. Primary-key policy now requires a valid Direct Key signature for v6 and takes its flags/expiration from that signature; a UID certification cannot replace it. Tests verify modern v4/v6 key import, encryption and trusted signed-message decryption, plus rejection after stripping the v6 Direct Key signature. This follows RFC 9580 section 10.1.1.

Compatibility
RSA, ECDSA/NIST-curve and 448-bit OpenPGP verification, encryption and imports are unavailable in this build. Existing key files are not modified on disk; unsupported imports fail. Applications needing these algorithms require a separately reviewed implementation. Supported Sanct key bundles, metadata, hybrid v1/v2 envelopes and unsigned OpenPGP interoperate in both directions with the saved pre-update and original benchmark WASM bundles. Signed OpenPGP still requires trusted signer keys through pgpDecryptMessageVerified.
The preceding dependency updates, memory cleanup, signature policy and resource limits remain in place. Their full description and earlier benchmark measurements are archived in REPORT-0.3-update.txt and REPORT-0.2-review.txt. Statements about unresolved advisories and publication status in those files describe earlier snapshots, not this build.

Validation
66 Rust tests pass (61 core, five bindings), including synthetic RSA/P-256 import rejection, a mixed supported-primary/unsupported-subkey fixture, unsupported generation, legacy and modern Curve25519 operations, verified signatures and stripped v6 metadata. Five JS tests pass, including input/output memory-cleanup fixtures and initialization/encoding checks. Native Clippy with -D warnings, workspace and vendor rustfmt, strict TypeScript and git diff --check pass. The optimized WASM build and self/prior-bundle interoperability tests pass, including WASM-level removed-provider rejection. No comments were added to code; upstream comments/test-only source were omitted from the vendored runtime. Checked-in secret-key fixtures are disposable synthetic test material.
The CI and release workflows keep the full cargo-deny gate and now check vendored formatting. The earlier release failed safely before creating a tag or release; publication is retried only with these checks passing.
